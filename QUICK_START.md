## 🔴 IF SOMETHING BREAKS

### App won't start
```powershell
# Check Python
python --version

# Check Streamlit
pip install streamlit

# Try again
streamlit run app.py
```

### No devices appear
- Click "🔄 Reset Devices"
- Select "🔵 Demo Devices (Simulated)"
- Click "🔍 Scan Devices Now"

### Demo doesn't run
- Go to "🚀 One-Click Demo"
- Uncheck "⚡ Fast Prototype Mode" 
- Click "✅ RUN FULL DEMO NOW"

### Flow Tracker doesn't show flows
- Demo devices are simulated (expected)
- Use real scan mode for actual network flows
- Still shows full UI and functionality

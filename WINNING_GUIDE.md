## 🔴 IF SOMETHING GOES WRONG

### App won't start
```
Check Python: python --version
Check Streamlit: pip install streamlit
Try again: streamlit run app.py
```

### Devices don't appear
1. Click "🔄 Reset Devices"
2. Try again
3. Use demo mode if real scan fails

### Demo doesn't complete
1. Uncheck "⚡ Fast Prototype Mode"
2. Click run again
3. Takes ~30 seconds

### Flow tracker shows 0 flows
**This is normal!** Demo devices are simulated. Real networks would show flows. Just show the UI.

### Firewall integration fails
**This is expected!** Requires admin. Use dry-run mode. Show the command that would execute.
